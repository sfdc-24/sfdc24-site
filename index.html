Studio architecture · design & measured gates

Four layers behind every working session

How spoken intent becomes verified Salesforce work: combining the live conference canvas and measured release checks (as of 6 Nov 2026) with the target voice-binding and dual-plane bus design.

01 · Voice-to-agent binding (target design)

Spoken intent routes directly to each bound agent

In the studio binding design, each persona on the line binds to its own working agent seat. A single-speaker floor lock keeps voices from talking over the room, while any irreversible action pauses for an explicit spoken read-back before it runs.

  • Floor design1 speaker at a time
  • Target route< 10 ms to bound seat
  • Safety gateSpoken read-back confirm

02 · Dual-plane event bus & state ledger (target design)

Target: sub-second event doorbells paired with an audited ledger

The target bus design separates speed from auditability: a fast event plane is designed to wake the assigned agent when a turn arrives (replacing polling loops), while an append-only state ledger records every handoff, enforces a design constraint of automatic token scrubbing, and feeds Jev to rank competing versions.

  • Target wakeupEvent doorbell + claim lock (replacing polling loops)
  • Design constraintAutomatic token scrub
  • GatekeeperJev ranks competing drafts

03 · Shared studio canvas & presenter seat (design)

Living cards and isolated screen-share seats

While you speak, Clay, Greg, Jemma and Cody build OmniScripts, FlexCards, Data Mappers and trade-off cards in place on one canvas. For screen-share walkthroughs, the presenter seat (/present/) is designed around a role constraint: screen frames only, with no microphone, audio, or data writes.

  • CanvasIn-place v1 → v2 updates
  • Presenter designScreen-only seat (/present/)
  • Design constraintPresenter view uses no microphone, audio, or data writes

04 · Takt release trains & measured break-it gates

Scheduled release trains with break-it verification

Changes ship on scheduled release trains. Before any train departs, an independent agent reviews the exact version, automated break-it checks (1,457 chair tests and 1,215 break-it checks measured 6 Nov 2026) run against it, and the release guard confirms no live call is interrupted.

  • Target cadenceScheduled release trains
  • Measured (6 Nov)1,457 tests + 1,215 break-it checks
  • Release guardIdle-line check + rollback snapshot

Multi-agent delivery model

From intent to release, on a fixed cadence

How one idea becomes shipped work: decomposed, dependency-mapped and delivered by an agent fleet working in parallel on scheduled release trains.

01 · Envision

Intent is captured before anything is built

An engagement begins as a concept — a customer website, a portal, an automation. The intent behind it is recorded as a working charter: the outcome sought, the constraints that bound it, and the measures that will say it worked.

02 · Blueprint

The work is decomposed into release trains

The charter is broken into workstreams and sequenced into dependency-mapped release trains. Placeholder estimates size the unknowns, and targeted scoping questions close the gaps until planning can stand on evidence.

03 · Mobilize

A timeline is committed and the fleet stands up

With sufficient information on scope and dependencies, a delivery timeline is committed. The agent fleet mobilizes against it: every workstream is assigned an owner before the first build starts.

04 · Execute

Agents drive parallel workstreams

The work runs side by side rather than in sequence: a logo is drafted, a layout is selected, reference material is gathered, and each build is reviewed — separate lanes, one coordinated delivery.

05 · Release

Fixed-cadence trains compress time to value

Everything ships on a takt. Release trains leave on schedule, scope that misses one train rides the next, and quality rises iteration over iteration while time to market stays short.

What works today

One line, four agents, one shared canvas

  1. 01 · Live conference line

    You talk, the team answers

    You speak, and Clay, Greg, Jemma and Cody answer by voice. Their work lands on a shared canvas while you are still talking.

  2. 02 · Living cards

    Ask for a change, the same card updates

    Say “make it shorter” or “make the logo bolder” and the card already on the canvas changes in place. No new copy to chase.

  3. 03 · Team cards

    Every agent’s version, side by side

    “Everyone, design a logo” gives one card with each agent’s version next to the others. You pick the one to keep.

  4. 04 · Discussion cards

    Pros, cons and a summary

    Ask for a discussion and get the pros and cons with a summary. The agents see each other’s cards and build on them.
