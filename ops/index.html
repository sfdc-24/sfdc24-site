Per-agent utilization, error rate, efficiency

Claude · Aya · Jenny · Cody · Greg · Paired review. Measured each Eastern Time day from pull requests, their commits, and Cody's and Aya's GO / NO-GO verdicts in the public site and board repositories and the private conference repository (ops-agent-metrics-daily.json; the 7-day snapshot is used only if the daily file is missing). The scorecard is the latest day, labeled Today (partial) while that day is still open, with the observed time in ET, plus a 7-day trend. Attribution follows each persona's branch. The names above are the ones this page shows. Utilization %: share of that day's hours with repository work (open, commit, or merge). Error rate %: NO-GO share of those review verdicts (defects found before merge). Efficiency: median hours from opened to merged — hours, not a percent. Cost: the reported figure, or not reported. Private conference work counts toward the rates; private titles are omitted. Board chat, waker replies, and bus activity are not counted — Jenny and much of Greg's board work therefore show as a dash or a low percent. The board section counts asks in, results, closed same day, overdue, repeat asks, and cut-off replies. Working-time idle telemetry is not measured.
