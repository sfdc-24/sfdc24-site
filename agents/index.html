Process

  1. 1. Visitor types. The line goes on the board in their own chalk.
  2. 2. Python gates. assets/triage.py owns the rules. Confident local answers never spend a token.
  3. 3. One handoff. A miss names one agent — never five at once — so ownership stays clear.
  4. 4. Reply path. The live flow on the homepage lights Typing → Python → agent → Response as it happens.
  5. 5. Check. Overclaim scan on the reply: nothing may claim to have read a live customer system.

Architecture
